👻 GhostStudy

Finds the dead time between MBA classes and quietly books it for the certification you keep postponing.

Class Club / meeting Ghost block (tap to mark done)

How it works

  1. Read the calendar. It pulls the class timetable and club commitments (sample week here).
  2. Find usable gaps. It skips anything shorter than your threshold and keeps 10 minutes of buffer after each class so you can walk out and breathe.
  3. Ghost-block them. It books the best gaps with the next module that fits, capped per day so the plan doesn't turn into a second timetable.
  4. Nudge, don't nag. One reminder right before a block, with the exact module to open.

This is a clickable concept prototype with a sample schedule and rule-based scheduling. It doesn't connect to a real calendar, and the module lists are illustrative.
